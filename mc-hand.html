控制逻辑预演方案

以 Create 模组的轴承与绳索滑轮模拟关节与腱绳，用齿轮变速与序列换挡控制弯曲角度， 在方块世界里先跑通「指令 → 动作」的完整流程，再映射到真实舵机与腱绳手。

01

能验证什么，不能验证什么

SCOPE

✅ 适合验证

  • 五指的动作时序：哪根先动、间隔多久
  • 控制链路：主端指令 → 各指独立响应
  • 抓握姿态组合：握拳、捏取、指向、对掌
  • 红石信号分配、互锁与复位逻辑
  • 多人联机演示与流程讲解

❌ 不适合验证

  • 连续角度与真实关节角（方块旋转是离散步进）
  • 腱绳张力、抓持力、摩擦与疲劳
  • 真实尺寸与干涉（1 方块 1 米的尺度失真）
  • 舵机扭矩、电流与发热
结论：MC 用来把「控制与动作流程」跑通，机械尺寸与受力仍需 Three.js / URDF / MuJoCo 或实物验证。 两者互补，不替代。

04

控制与信号分配

CONTROL ARCHITECTURE

纯红石替代（无 Create）

  • 粘液块 + 活塞：两态夹爪（开 / 合）
  • 观察者 + T 触发器：单脉冲步进
  • 红石中继器调延时：模拟动作间隔
  • 优点：原版即可；缺点：只有两态，无角度

ComputerCraft 进阶（可选）

  • CC 电脑 + 红石 I/O 输出 5 路信号
  • Lua 脚本定义姿态：握拳 / 捏取 / 指向
  • 可读取聊天或文件指令，模拟主端下发
  • 未来与实物通讯协议同构：S,指,角
与实物对齐：把「换挡脉冲数」当作舵机角度，「转速控制器」当作 PWM 频率， 这套逻辑可直接换成 ESP32 + SG90 的控制代码。
05

动作时序表

POSE SEQUENCE

姿态动作顺序延时对应实物
张开 全部换挡反向脉冲 ×1，回位 0 tick 弹簧回位至初始角
握拳 中指 → 无名指 → 食指 → 小指 → 拇指 每指间隔 4 tick 依次收拢，防打架
捏取 拇指 + 食指同时脉冲 ×2，其余不动 同步 两指对捏轻物
指向 仅食指伸直，其余收拢 先收后指，间隔 6 tick 指示动作
对掌 小指 + 拇指相向，形成环 同步 拇指对掌测试
急停 主离合断开 立即 断电保位
06

搭建步骤

BUILD ORDER

定基础与动力舱先铺掌部平台 8×3，下方放转速控制器、离合器与动力源；用创造马达最快，正式版换风车/蒸汽机。
装指根轴承在掌前缘按食指—小指位置放 5 个机械轴承（拇指侧置偏转约 20°），确认转动无遮挡。
接指节与关节每指用 5 格方块构成三节，节间放小型轴承或直接用整段；先做一根手指试转。
加绳索滑轮每指背部布 1 个绳索滑轮并连绳至指尖，模拟腱绳牵拉；调节初始长度。
接序列换挡为每个轴承接换挡机构，脉冲一次转固定角；用红石链路连到控制台。
做控制台5 个模拟拉杆 + 主离合 + 反向；墙面贴 Nixie 管显示状态，便于演示讲解。
跑姿态序列按第 5 节表格调延时，依次验证握拳、捏取、指向、对掌。
记录与映射把每个姿态的脉冲数、延时记下来，作为实物舵机角度与动作间隔的初值。
尺度提醒：1 方块 = 1 米，所以这只手会是「巨型机械手」。若想接近真人尺寸观感， 可用小方块模组（Chisels & Bits / LittleTiles）把比例缩到 1/4，或接受它作为「演示装置」的定位。
