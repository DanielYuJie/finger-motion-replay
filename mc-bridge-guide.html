让真实的手驱动 Minecraft 机械手

03电脑端：三步启动

PC SIDE

  1. 启动中继服务 在本目录执行：python bridge_server.py　看到「监听 http://127.0.0.1:8765」即可。
  2. 打开采集页并开摄像头 浏览器打开 capture.html → 点「开启摄像头」→ 允许权限。 右侧「MC 桥接」勾上推送关节角到 CC:Tweaked，状态应变成「已连接 · N 帧」。
  3. 验证链路 浏览器访问 http://127.0.0.1:8765/angles，能看到五指 flex 数值随你的手变化，说明主端通了。
自检：手离开画面 1 秒后，/angles 里 hand 会变 false，机械手会自动松开回零。

04游戏端：接线

REDSTONE WIRING

电脑 6 个侧面各接一根红石线，一根控制一根手指。序列换挡配成「脉冲一次转 15°」。

电脑侧面手指接到
left（左）拇指拇指的序列换挡
top（上）食指食指的序列换挡
bottom（下）中指中指的序列换挡
right（右）无名指无名指的序列换挡
front（前）小指小指的序列换挡
back（后）—空余（可接指示灯）

序列换挡怎么配

  • 信号 ON → 旋转 +15°
  • 信号 OFF → 旋转 −15°

这样一串脉冲就能「推」或「拉」手指。mc_hand.lua 里 STEP_DEG = 15 要和这里一致。

05把脚本装进电脑

INSTALL LUA

在游戏里对着 CC 电脑右键打开终端，输入 edit mc_hand.lua，把下面代码整段贴进去，Ctrl → 保存 → 退出。然后执行：

mc_hand.lua

脚本文件也在本目录：mc_hand.lua

06调参与排错

TUNING & TROUBLESHOOTING

现象原因处理
电脑里 http.get 报错 / 返回 nilHTTP API 没开检查 computercraft-server.toml 里 http.enabled = true，改完重启游戏
采集页显示「未连接」中继服务没启动先跑 bridge_server.py，再刷新采集页
手指一直抖 / 来回弹死区太小把 DEADBAND 从 8 调到 12–15
手指方向反了换挡 ON/OFF 的旋转方向配反在游戏里调换序列换挡的两个角度，或对调脚本里的加减号
动作慢吞吞MAX_PULSE 太小从 3 提到 5，或把 POLL 调小到 0.05
手指乱甩脉冲太密把 PULSE_ON/PULSE_OFF 提到 0.1，或降低 MAX_PULSE
弯曲幅度不够MAX_DEG 限制提到 120（注意别让机构自撞）
核心难点：Create 没有角度传感器，只能增量式控制——脚本内部记着每指当前角度， 每次只补「还差几个脉冲」。所以脚本重启后角度计数归零，机械手会与实际位置不同步， 此时手动把所有手指推到张开状态再跑脚本即可。
