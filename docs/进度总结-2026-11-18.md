### 3. 小程序手部识别优化（20:38）

| 改动 | 作用 |
| --- | --- |
| `update3DMode({open3d:true})` | 拿到深度，避开「手掌正对镜头时投影不变」的误判；失败静默退回 2D |
| 角度 + 曲率比双度量（0.6 / 0.4） | 单关节角残差靠整指形态兜住；拇指 CMC 权重降到 0.35 |
| 软死区 `≤8→0`、`≥92→100` + 5% 量化 | **张开真的输出 0**，舵机不再阈值附近微动 |
| 置信度门槛 `confidence<0.4` | 劣质点不再被解成角度推给舵机 |

实测（合成数据）：伸直全 0、弯 90°→45、手指朝镜头弯 2D 判 21 → **3D 判 43**；回归 `test/verify.js` 60/60。

文档：`docs/手部识别优化.md`
